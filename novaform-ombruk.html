E-post (EmailJS + Outlook)
Opprett gratis konto på emailjs.com, koble til Outlook.
HVOR FINNER DU DISSE?
① Public Key → klikk brukernavnet ditt øverst til høyre → Account → General
② Service ID → Email Services → klikk tjenesten → ID vises øverst på siden
③ Template ID → Email Templates → klikk malen → ID vises øverst på siden
MAL-OPPSETT I EMAILJS
Appen genererer selve teksten med AI. EmailJS-malen trenger bare disse feltene:
Subject: {{subject}}
To email: {{to_email}}
To name: {{to_name}}
Reply to: {{from_name}}
Message: {{message}}
